# Trafficity — дуэль маршрутов

Trafficity — минималистичная стратегия про гонку по городскому графу. Каждая сторона управляет двумя машинами и старается доставить больше заказов за 30 ходов, прокладывая маршрут прямо на карте и задерживая соперника точечными остановками.

## Быстрый старт

```bash
npm install
npm start
```

По умолчанию сервер поднимется локально на `http://localhost:3000`. Скрипт [`start_servers.bat`](./start_servers.bat) на Windows установит зависимости, запустит туннель Cloudflare (`cloudflared tunnel run irgri-tunnel`) и поднимет сервер.

Для подключения из сети используйте домен `https://irgri.uk/` — клиент автоматически обращается к нему в онлайн-режиме.

## Режимы игры

- **Одиночный** — вы против автопилота. По две машины на сторону.
- **Локальный мультиплеер** — 2–4 игроков за одним устройством.
- **Онлайн** — клиент автоматически подключается к `https://irgri.uk/` и подбирает свободное лобби.

## Управление

- **Выбор машины** — нажмите на карточку справа или прямо на машину на карте.
- **Планирование маршрута** — зажмите свою машину на карте и протяните линию через узлы до цели. Узлы подсвечиваются при приближении; обратный ход удаляет последний сегмент. Маршрут фиксируется автоматически, когда вы отпускаете палец/кнопку на целевом узле.
- **Стоп на узле** — выберите задержку (1–5 ходов) ползунком и перетащите жетон «Стоп» на нужный узел. Машина выдержит паузу, когда окажется на этом узле.
- **Показ узлов** — кнопка в шапке включает/выключает отображение сетки узлов.
- **Следующий ход** — запускает симуляцию перемещения всех машин. В онлайне доступна активному игроку.

Журнал событий фиксирует полученные маршруты, паузы и завершённые доставки.

## Система очков

1. За ход каждая машина проходит одно ребро, если не стоит на стопе.
2. Достигнув цели, машина получает новую точку назначения и приносит `max(10, 40 − 2 × пройденные шаги)` очков.
3. Побеждает игрок с наибольшим счётом после 30 ходов.

Все дороги двусторонние. Узлы скрыты по умолчанию, но их всегда можно подсветить для точного планирования.

## Онлайн-лобби

1. Выберите режим «Онлайн», укажите имя диспетчера и нажмите «Подключиться» — игра сама создаст лобби или присоединит вас к свободному.
2. После подключения дождитесь второго игрока. Статус комнаты и список участников отображаются в правой колонке.
3. Когда в комнате минимум два участника, хост запускает матч кнопкой «Следующий ход».
4. Сервер передаёт состояние после каждого хода и объявляет победителя по завершении лимита.

## Структура проекта

- `index.html`, `style.css`, `game.js` — клиент с холстом карты и логикой симуляции.
- `server/index.js` — Express + WebSocket-сервер для локальной/онлайн-игры.
- `start_servers.bat` — помощник для Windows с установкой зависимостей и запуском туннеля.
