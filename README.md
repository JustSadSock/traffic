# Маршрутчики v0.2 — прототип

Минимально рабочий прототип под браузер: один игрок против «ничейного» трафика NPC. 
Рендер на canvas, без сторонних библиотек.

## Как запустить
Откройте `index.html` в любом современном браузере. Никакого сервера не требуется.

## Управление
- **Маршрут**: инструмент «Маршрут», кликайте соседние узлы, чтобы проложить путь.
- **Светофор**: инструмент «Светофор», клик по перекрестку — планируется ручной свитч (вступает через 1 ход). Снимает деньги.
- **Односторонний**: инструмент «Односторонний», клик по ребру — устанавливает временное одностороннее (NPC избегают), снимает деньги.
- **Ожидание**: инструмент «Ожидание», клик по узлу вашего маршрута — введите время ожидания (0..3).
- **Пересчитать маршрут**: авто-поиск пути до цели. Берется плата (5₵ + 1₵ за ребро изменения).
- **Закончить ход**: применяет отложенные действия, тикают светофоры, едут машины, начисляются выплаты/штрафы.

## Правила (кратко)
- 30 ходов. Машина движется на 1 ребро за ход.
- Доход: `100₵ + 5₵×L` + бонус скорости `max(0, 20 − T)×2₵`. Чистый рейс ×1.2.
- Штрафы: ДТП −100₵ и простой 2 хода, красный −30₵ (в данной сборке не вызывается), блокировка −10₵/ход.
- Светофор: автосмена 3/3, ручной свитч 10₵, КД 3 хода, удорожание в окне 10 ходов.
- Односторонний: 15₵, длится 3 хода, КД ребра 5 ходов.
- Правки маршрута платные.

## Что упрощено
- Нет мультиплеера и ИИ-соперника (есть только NPC-трафик).
- Столкновения сведены к «вежливому стопу» при полной ничьей приоритета.
- Нет «приоритетного коридора» и сложных событий. Их несложно добавить в `game.js` по аналогии с односторонним.

## Структура
- `index.html` — UI и холст
- `style.css` — оформление
- `game.js` — логика графа, светофоров, машин, экономики, рендера
