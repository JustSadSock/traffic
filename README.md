# Маршрутчики — прототип v0.2

Минималистичная переработка диспетчерской игры по финальной редакции правил «Маршрутчиков». Интерфейс рассчитан на одиночную игру: две маршрутки против оживлённого NPC-трафика, адаптивная вёрстка для настольных и мобильных устройств и мягкая палитра с настраиваемыми темами.

## Быстрый старт

```bash
npm install
npm start
```

Сервер поднимает клиент на `http://localhost:3000`. Для Windows остался сценарий [`start_servers.bat`](./start_servers.bat), который устанавливает зависимости и запускает сервер одной командой.

## Главное меню

На стартовом экране выберите одну из трёх атмосфер игры:

- **Будний рассвет** — чистая игра по правилам v0.2.
- **Базарный день** — усиленный трафик и повышенные штрафы.
- **Ночная смена** — редкий трафик, но ошибки обходятся дороже.

Дополнительно можно переключать палитры: «Рассвет», «Мятный снег», «Сумерки».

## Управление

- **Поле** — кликабельная карта графа. Узлы с круговой подсветкой имеют светофоры.
- **Выбор маршрутки** — нажмите на цветной квадратик. В боковой панели отобразятся текущая цель и статистика.
- **Маршрут** — кнопка «Построить маршрут» открывает редактор. Кликните по узлам карты, чтобы задать путь. Изменения применяются в начале следующего хода и стоят `5₵ + 1₵` за каждое новое ребро сверх оплаченной длины.
- **Ожидание** — кнопка «Настроить ожидание» позволяет задать задержки 0–3 хода на узлах текущего маршрута без дополнительной платы.
- **Переключение светофора** — режим со стоимостью 10₵ + 10₵ за каждое повторное вмешательство на том же перекрёстке в течение 10 ходов. Кулдаун: 3 хода.
- **Временный односторонний** — ставится на ребро за 15₵, действует 3 хода и уходит в кулдаун на 5 ходов. Ограничивает только NPC-трафик.

Кнопка «Отмена» сбрасывает любой активный режим, а журнал фиксирует все заявки, штрафы и выплаты.

## Ход игры

Каждый ход состоит из трёх фаз:

1. **Применение планов** — маршруты, светофоры и знаки, запрошенные на предыдущем ходу, вступают в силу. Деньги списываются при постановке заказа.
2. **Симуляция** — светофоры тикнут (3/3 фазы), проверяются кулдауны односторонних знаков, спавнятся и едут NPC (скорость 1 ребро за ход, учитывают односторонние). Маршрутки двигаются по маршрутам с учётом ожиданий. Конфликты решаются по приоритету светофора; при полном равенстве срабатывает «вежливый стоп» и все участники остаются на месте.
3. **Экономика** — начисляются выплаты за завершённые рейсы и штрафы за блокировку перекрёстков (`-10₵` за ход, с учётом множителя сценария).

Смена длится 30 ходов. После завершения указывается итоговый баланс и количество рейсов.

## Экономика рейсов

- **Доход**: `100₵ + 5₵ × L`, где `L` — количество фактически пройденных рёбер.
- **Бонус скорости**: `max(0, 20 − T) × 2₵`, где `T` — количество ходов в пути.
- **Чистый рейс**: ×1.2, если маршрутка ни разу не блокировала перекрёсток.

Новые цели назначаются автоматически в радиусе 6–18 рёбер от текущего узла. В левой панели подсвечиваются актуальные направления, а при клике по NPC отображается прогноз его пути на 5 узлов вперёд и ориентировочный ETA.

## Структура проекта

- `index.html`, `style.css`, `game.js` — клиентская часть и симуляция.
- `server/index.js` — express-приложение, которое отдаёт статику и поддерживает WebSocket-заготовку.
- `start_servers.bat` — автоматический запуск сервера на Windows.

Игра хранит всё состояние на клиенте — сервер требуется только для локального хостинга.
