# Маршрутчики — дуэль маршрутов

Минималистичная стратегия про гонку маршрутов: каждая команда управляет двумя маршрутками и пытается доставить больше заказов за 30 ходов. Карта напоминает настольный граф с милой пастельной палитрой, а управление адаптировано под компьютер и телефон.

## Быстрый старт

```bash
npm install
npm start
```

Приложение запустится на `http://localhost:3000`. На Windows можно воспользоваться скриптом [`start_servers.bat`](./start_servers.bat), который установит зависимости и поднимет сервер.

## Режимы

На стартовом экране доступны три формата:

- **Одиночный матч** — вы против автопилота. У каждой стороны по две маршрутки.
- **Локальная дуэль** — от 2 до 4 игроков за одним устройством. Все действуют на одной карте, по две машины на игрока.
- **Онлайн** — создайте лобби, поделитесь кодом и сыграйте с друзьями на `localhost:3000`. Игра начинается, когда хост нажимает «Следующий ход» после подключения минимум двух игроков.

## Управление

- **Выбор машины** — кликните по карточке в правой панели или по самой маршрутке на карте.
- **Маршрут** — кнопка «Задать маршрут» открывает режим планирования. Кликайте по дорогам, следуя связям графа. Последний узел должен совпадать с целью. Список в модальном окне позволяет откатить путь.
- **Стоп** — кнопка «Стоп на узле» добавляет задержку на 1–5 ходов для выбранной маршрутки. Действие применяется в начале следующего хода.
- **Показ узлов** — кнопка в шапке включает/выключает отображение всех узлов карты.
- **Следующий ход** — запускает симуляцию перемещения для всех машин. В одиночном режиме и локальной игре ход доступен всегда, в онлайне — только активному игроку (обычно хосту).

Журнал в правой колонке фиксирует ключевые события: новые маршруты, остановки, перемещения и завершение доставок.

## Геймплей и очки

1. **Планирование** — задайте маршруты и задержки для своих машин.
2. **Ход** — каждая машина проходит одно ребро, если не стоит на стопе. Если маршрут пуст, машина ждёт указаний.
3. **Доставка** — достигнув цели, маршрутка приносит очки и получает новую точку назначения. Стоимость рейса: `max(10, 40 − 2 × шаги)`. Побеждает игрок с наибольшим количеством очков после 30 ходов.

Все дороги двусторонние. Узлы скрыты по умолчанию, но их можно подсветить, чтобы удобнее прокладывать маршрут. Дополнительно на карте отмечены милые ориентиры (дом, рынок, пляж и т. д.), которые служат целями рейсов.

## Онлайн-лобби

1. Хост выбирает режим «Онлайн» и действие «Создать лобби». На экране появится код комнаты.
2. Гости вводят код и свои имена.
3. Когда готовы минимум двое игроков, хост нажимает «Следующий ход», чтобы запустить партию.
4. Во время игры только активный игрок может завершать ходы, но каждый может перенастраивать маршруты своих машин в любой момент.
5. По завершении 30 ходов сервер объявит победителя и вернёт всех в лобби.

## Структура проекта

- `index.html`, `style.css`, `game.js` — клиентская часть, карта и логика симуляции.
- `server/index.js` — express + WebSocket-сервер для онлайна и статической выдачи.
- `start_servers.bat` — вспомогательный скрипт для Windows.
