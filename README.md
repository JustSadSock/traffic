# Маршрутчики — современная редакция

Обновлённый прототип диспетчерской игры с поддержкой одиночного режима, локального мультиплеера и онлайн-партий.

## Особенности

- Современный интерфейс с адаптивной версткой.
- Одиночный режим против NPC с настраиваемой сложностью.
- Локальная игра для 2–4 человек за одним устройством.
- Онлайн-лобби с возможностью создания и подключения по коду.
- Сервер на Node.js (Express + WebSocket) для синхронизации партий.

## Запуск

```bash
npm install
npm start
```

Сервер поднимается на `http://localhost:3000` и автоматически отдаёт клиентскую часть. Для Windows добавлен сценарий [`start_servers.bat`](./start_servers.bat), который устанавливает зависимости при первом запуске и стартует сервер.

## Структура

- `index.html`, `style.css`, `game.js` — клиентская часть.
- `server/index.js` — сервер и WebSocket-обработчики.
- `start_servers.bat` — батник для быстрого запуска на Windows.

## Игра

Выберите режим на стартовом экране. Управление осуществляется кликами по перекрёсткам. Собирайте пассажиров, перемещая маршрутки по узлам графа. Каждый подобранный пассажир приносит 12₵. Раунд длится 40 ходов.
